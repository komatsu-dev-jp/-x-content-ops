# ペルソナ採点表・30/90日プラン・見直しベンチマーク

`x-account-launch` の STEP 5・STEP 6 で使う。

---

## 1. 3秒テスト（最初に通す関門）

プロフィールを開いた人が3秒で判断する。次の3問に、表示名＋アイコン＋bioの1画面だけで
答えられなければ不合格。**ここを通らない設計は他が良くても作り直す。**

1. **この人は何の人か**（1レーンに読めるか。2つ以上に読めたら不合格）
2. **フォローすると自分に何があるか**（メリットが具体か。「発信します」だけは不合格）
3. **なぜこの人が言うのか**（実績・立場・作っているもの・実験量のどれかがあるか）

---

## 2. 採点表（100点／85点以上で通過）

| 項目 | 配点 | 見るところ |
|------|------|-----------|
| レーンの狭さ・一貫性 | 20 | 1レーンに絞れているか。表示名・bio・固定ポスト・7日分のテーマが同じ方向を向いているか |
| 3秒テスト | 20 | 上記3問に答えられるか（各約7点） |
| bioの構造と情報量 | 15 | 4行構成／160字以内／検索キーワードあり／フォローするメリットが具体 |
| 表示名の設計 | 10 | 検索語を含む／50字以内／読みやすい／覚えられる |
| アイコン・ヘッダー方針 | 10 | 人間味があるか／小サイズで判別できるか／量産型を避けているか |
| 固定ポストの強さ | 10 | 価値が一瞬で伝わるか／実在する素材だけで作れるか |
| 30日運用の実行可能性 | 10 | ユーザーの持ち時間で回るか。一次情報の供給源があるか |
| 事実の健全性 | 5 | 盛りゼロ／未確認の明示／外部事実の断定なし |

**減点（該当したら即時マイナス、合計から引く）**
- 実績・数字をこちらで捏造した: −30（作り直し）
- 自動投稿/自動フォロー/自動いいねを前提にした: −20
- 「必ず伸びる/稼げる」等の断定: −20
- 複数レーンの同時運用を初期設計に入れた: −15
- ハッシュタグ3個以上を前提にした: −5

---

## 3. 最初の30日プラン（ステージ1: 0→1,000の骨格）

このレーン共通の骨格を、選んだレーンの言葉に置き換えて使う。

### 週の基本形

| 項目 | 目安 |
|------|------|
| 投稿本数 | 1日3〜5本（新規アカウントは上限8本を超えない） |
| 型ミックス | 実用40% / 一次情報・実験ログ30% / 共感20% / 意外性10% |
| リプ周り | 1日15〜30分。自分の1〜10倍規模のアカウントへ。具体的に返す |
| 本気のスレッド | 週1本 |
| 振り返り | 週1回。上位3投稿と下位3投稿を、ペルソナ一致度の観点で見る |

### 型の中身

- **実用（保存される）**: チェックリスト、プロンプト集、図解、手順、失敗回避リスト
- **一次情報・実験ログ**: 具体的なツール名で「自分が試した結果」。数字・スクショ・失敗を出す
- **共感**: 読者ペルソナ（3年前の自分）の詰まりどころを言語化する
- **意外性**: 期待と違った結果、思い込みが崩れた瞬間

### リプ周りの質基準

- 相手の言葉を1つ拾う
- 「勉強になります!」だけは送らない。「〇〇の部分、明日試します」まで具体化する
- 同じ文面の連投をしない（スパム判定・凍結リスク）
- 1日の返信は質重視で3〜7件

### 4週の進め方

| 週 | やること | 終わりの状態 |
|----|---------|-------------|
| 1週目 | プロフィール確定、固定ポスト投稿、毎日3投稿、リプ15分 | 投稿21本・自分の型が2つ分かる |
| 2週目 | 反応の良かった型を1つ増やす、リプ30分へ | 反応の初速が読めるようになる |
| 3週目 | 週1の本気スレッド開始、一次情報の頻度を上げる | 保存される投稿が1本出る |
| 4週目 | 上位投稿へ固定ポストを差し替え、bio 1行目を微調整 | 次の30日の仮説が1つ立つ |

### 週次で見る指標（この順）

1. プロフィールクリック → フォロー（ペルソナが効いているか）
2. ブックマーク（保存される価値があるか）
3. 初速: 投稿後30〜60分の反応
4. リプライ・会話の数
5. インプレッション（参考程度。移行期は荒れる）

## 4. ステージ2（1,000→5,000、3〜9ヶ月目）の要点

初期設計では「予定」として1行触れるだけにする。実行はステージ1が終わってから。

- 伸びた形式を掘る（AI系クリエイターの場合、多くは短尺動画/デモ）
- 自分の資産になる導線を作る: bio・固定ポストに note/LINE/メルマガ →
  無料の見込み客獲得コンテンツ → 有料オファー
- 週次で分析、月次でbio微調整、四半期でペルソナ見直し
- 幅を広げるのは3,000〜5,000フォロワーを超えてから

---

## 5. 見直しベンチマーク（この数字が出たら設計を変える）

| 症状 | 解釈 | 次の一手 |
|------|------|---------|
| エンゲージメント率が0.5〜1%未満 | 投稿とペルソナのミスマッチ | フックとbioの整合性を見直す |
| プロフィールクリック率が低い | 1行目が弱い | 冒頭の型を変える |
| フォロワーは増えるがインプレッションが横ばい/減少 | `[観測]` 2025〜2026年の既知のプラットフォーム変動 | 焦って戦略を変えない。リプ周り・ネイティブ動画・自分の導線を強化 |
| 6〜8週間続けて300フォロワー未満 | ニッチが広すぎる、またはアイコン/bioが3秒テストに落ちている | レーンを1段階狭める |
| 保存されない | 実用型の密度不足 | チェックリスト/手順型を増やす |

到達目安（保証ではない）: 約2,000でDM/PR流入、約10,000でPR案件（1投稿3〜10万円程度）。

---

## 6. やらないこと（初期設計に入れてはいけないもの）

- 「何でも屋」的な広いスタート、毎週テーマを変えること
- 自動投稿/自動フォロー/自動いいね、大量転載（凍結リスク）
- AI出力をそのまま投稿すること（必ず人の手で自分の声と実例を入れる）
- 画一的な大量リプライ、リンクスパム
- 純粋なインプレッション稼ぎ、ネガティブ発言（一時的に伸びてもファンは残らない）
- AI生成の数字をファクトチェックせずに出すこと
- ALTテキストの省略、ハッシュタグの使いすぎ
