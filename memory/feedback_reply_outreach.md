# リプ周り・返信の学習

## 1. パチンコ用語・当たりの良し悪しを事実確認してから返信する

- 失敗例: 「チャージあたり」を“良い当たり”と誤読し、嘆きツイートに祝福調で返信案を作った。
  実際は「チャージ＝出玉のしょぼい最悪の当たり」で、相手は嘆いていた。
- **Why:** 用語の良し悪しを取り違えると、共感どころか相手を逆撫でする。EV/データ系の相手には特に「分かってない人」と見られ信頼を失う。
- **How:** 機種名・予告・当たりの種類・店舗挙動の意味に確証がなければ、断定せず本人に確認する。曖昧なまま「良かったですね/最悪ですね」のトーンを決めない。

## 2. 嘆き・自虐ツイートに「おめでとう/羨ましい」は厳禁

- 投稿の感情（自慢か嘆きか）を先に判定してからトーンを決める。`...` や `^_^` 等のニュアンスも読む。

## 3. 閉じた会話は無理に開けない

- `^_^`＋過去形（「移動しました」）の自己完結報告は実質クローズ。質問リプを投げると不自然。
- **How:** クローズ気味の投稿は「いいね＋フォローして見送り」。相手の“迷い・愚痴・問い”が出た開いた投稿で初めて絡む。リプ周りは数より「開いてる投稿を見抜く」のが効率の肝。

## 4. コールド返信に宣伝・リンク・アプリ名を入れない

- 相手が興味を示してから初めてPachiTrackerを出す（`reply-outreach-playbook.md`）。

## 5. パチンコ機種名・用語を「スルー数」「回数」と混同しない

- 失敗例: 「5SP」を「5スルー（5回スルーした）」と誤読し、「5SPまで粘って」という表現を使った。正しくは「5SP」は海物語シリーズの機種名。
- 「スルーが鉄壁すぎて辛かった」の正確な意味: スルーチャッカーを球が通らない → 電サポ（電チュー）が開かない → 持ち玉が削られる → 1R出玉とサポ増減の数値が悪化 → 遊タイム期待値が削られる、という連鎖。「回転率が低い」という単純な話ではなく電サポが機能しないことが根本原因。
- **How:** 数字＋アルファベットの組み合わせ（例: 5SP, MAX8）は機種名の可能性が高い。スルー・電サポ・サポ増減・持玉比率の関係を正しく理解してから返信する。

## 6. 相手が「すでに知っている・やっていること」を質問・説明するな（当たり前NG）

- 失敗例（質問編）: Sくんが詳細データ（1k回転数・1R費用）を自分で計算して投稿しているのに「このデータってその場でメモしてますか？」と聞いた。相手はすでにやっており、反応が薄くなった（「お疲れ様です。その場でメモしてます！」と冷たい一言で終了）。
- **Why:** 投稿内容から明らかに分かることを質問すると「自分の投稿読んでない人」「話が噛み合わない人」と思われる。信頼ではなく疑問符を与える。
- **How:** 返信前に「この人がすでにやっていること・知っていること」を整理してから質問を作る。質問は「相手がやっていないこと」か「もう一段深い話」を聞く形にする。例：「メモしてますか？」→NG / 「メモしたデータ、後で何かに使ってますか？」→OK。
- **再発 (2026-07-03):** C.C.（データカウンタの履歴画像を毎回添付する垢）に「この履歴って毎回撮ってます？」と質問する案を出した。履歴スクショを撮るのはこの層には当たり前の習慣で、同じNGパターン。
- **再発・説明編 (2026-07-04):** りちゃのんの「くるみバレ」投稿への返信で、演出の内容（保留入場時の先バレ・プチュン・ラッシュ75%確定）を本人に向けて解説する文面を作った。指摘: 相手はその演出を知っているからこそ話題にしている本人＝その界隈の当事者。用語の意味を相手に説明し返すと不自然かつ「分かってない人が調べて言ってる」ように見える。
- **How（説明編）:** 用語の意味を**自分が理解するために事前に確認する**のは必須（rule 1/5）だが、**その説明を返信本文にそのまま書き戻さない**。確認した知識は「話を噛み合わせるため」にだけ使い、文面では相手が使った言葉をそのまま拾って反応する（例: 「くるみバレ、あの瞬間反則級ですよね」はOK／「くるみバレは保留入場時の先バレ演出で〜」と解説するのはNG）。**候補作成時に必ずこの項目を再確認すること。**
- **再発・数値編 (2026-07-08):** おじねこ氏の投稿（画像に「積み:21,505円」＝期待値+21,505円と明記済み）への返信案で「大海はまだ期待値ある感じですか？」と質問した。**画像内にすでに答え（期待値の数字）が書かれているのに、その有無を聞いてしまった。** 数字入りのスクショが添付されている投稿では、**画像内の数値も「相手がすでに開示済みの情報」に含めて当たり前質問チェックを行うこと**（本文だけでなく画像も確認対象）。
- **再発・自明な答えしかない質問編 (2026-07-13):** パチっこ氏の投稿（19回転に届かないと予想して早めに切り上げ、別台へ切替）への返信案で「それ回転数で見切りました？」と聞いた。指摘:「当たり前です。でなければなんで見切るんですか？」— **相手の投稿がすでに「予想して切り上げた」と述べている以上、判断基準が回転数（見込み）であることは自明で、それを確認する質問には価値がない。** 相手が明言済みの内容を聞き返しているだけで、質問というより「話を聞いていない」印象を与える。**How:** 「何を基準に判断したか」を聞く前に、投稿本文がすでにその基準を述べていないか確認する。述べている場合は基準を聞き返さず、rule 7の軸（具体的な閾値・タイミング・次にどうするか）へ質問をずらす（例:「回転数で見切りました？」→NG／「何回転までなら様子見る派ですか？」「切り上げ、迷いはなかったですか？」→OK）。

## 7. 期待値稼働勢には「回ってれば打つ」が大前提。それを崩す質問をしない

- 失敗例1: わーさん（プロ）の5万発投稿に「どこまで出たら終えるかの判断も変わりそう」という切り口で質問案を作った。プロは期待値がある限り打つのが大前提なので、「出玉額でやめる」という発想自体が期待値稼働と噛み合わず、「分かってない人」に見える。
- **再発 (2026-07-04):** ラントォの初当たり間隔報告（178→83→78→106）に「単発中心だと続行判断が変わるか」と聞く案を出した。指摘: 「回ってれば基本期待値稼働している人は打つ」のが大前提で、単発/連続という当たりの"質"で続行判断が変わるという発想自体がズレている。
- **Why:** 期待値稼働勢の続行/撤退の分岐点は「回転率が期待値ラインを割るかどうか」「そもそも期待値があるかどうか」であって、出玉の多寡や当たりの中身（単発か連続か）ではない。
- **How:** 期待値稼働勢への質問は次の軸に寄せる:
  - 「期待値があるかどうか」（据え置き・イベント日・スランプグラフの状況など）
  - 「回転率が何回転（何分の1くらい）まで下振れても様子を見るか」という自分基準の閾値
  - 台選び・スペック評価・資金配分
  - 出玉額・当たりの質（単発/連続）を理由にした続行/撤退判断は聞かない。相手のプロフィール・普段の投稿から「期待値稼働勢/プロ」だと分かったら、この軸に必ず切り替える。

## 8. リプ候補が「インタビュー」っぽく重い・硬い（全体的な傾向）

- 失敗例 (2026-07-10): パチこばさんの投稿（連敗中・明日甘デジから挑戦・「勝ちにこだわりたい」）への返信案「『どんな少額でもいいから勝ちにこだわりたい』、連敗中の時ほど大事な感覚だと思います。明日の甘デジ、"ここまで出たら勝ち"みたいな自分の中のラインって決めてます？」に対し、「インタビュー感が強すぎる。軽い感じの方がいい。これに限らず全ての投稿が重たく硬い」との指摘。**特定の1件ではなく、この期間に作った候補全体に共通する問題として指摘された。**
- **Why:** 「①相手の言葉を引用 → ②共感コメント → ③狭い質問で締める」というテンプレ構造を毎回100%律儀に実行すると、内容は正しくても文体が硬くなり、雑談ではなく取材（インタビュー）のように見える。X上の自然なリプは、質問なしで終わる・短い相槌だけ・くだけた言い回しの方が多い。
- **How（型の適用そのものを軽くする）:**
  - **質問は毎回つけない。** 「狭い質問」は3原則の1つであって義務ではない。共感・一言リアクションだけで終わる案を優先候補にすることが多いはず。
  - **文を短く切る。** 「〜だと思います。〜って決めてます？」のような書き言葉的な二段構成をやめ、「わかりすぎる…！」「それ地獄ですね笑」のような口語の相槌を混ぜる。
  - **「本人の言葉を引用してから展開する」型を毎回使わない。** 引用→共感→質問、という同じ順序を繰り返すと文体が均一化してテンプレ感が出る。順序や有無を毎回変える。
  - **候補を作ったら「これは友達に送るLINEっぽいか、記者会見の質問っぽいか」を自問する。** 記者会見寄りなら短く崩す。
  - **迷ったら短い方を選ぶ。** 1〜2文の共感だけで十分なことが多い。

## 用語の確認情報（分かったら随時追記）

事実確認できた専門用語はここに残す。次回から同じ用語が出たら断定してよい。

- **くるみバレ（リコリコ）**: 保留入場時の先バレ演出。画面がプチュンと消えて大当たりが1発告知される。かつラッシュ（継続）75%確定の演出。出現すると気持ちよく、「心臓がドキッとする」レベルの当たり演出（2026-07-04、ユーザーより確認）。
- **「積み」と「収支」（期待値稼働の実績報告フォーマット）**: 「積み」は**期待値**（例: P toolsの期待値計算結果の額）を指す。「収支」は**実際の結果**（実収支額）。両者は別の数字であり、「積み」を実収支と誤読しない（2026-07-08、ユーザーより確認。おじねこ氏の投稿「積み:21,505円／収支:39,347円」で確認——この回は期待値を上回る収支だった）。
