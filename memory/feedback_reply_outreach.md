# リプ周り・返信の学習

## 1. パチンコ用語・当たりの良し悪しを事実確認してから返信する

- 失敗例: 「チャージあたり」を“良い当たり”と誤読し、嘆きツイートに祝福調で返信案を作った。
  実際は「チャージ＝出玉のしょぼい最悪の当たり」で、相手は嘆いていた。
- **Why:** 用語の良し悪しを取り違えると、共感どころか相手を逆撫でする。EV/データ系の相手には特に「分かってない人」と見られ信頼を失う。
- **How:** 機種名・予告・当たりの種類・店舗挙動の意味に確証がなければ、断定せず本人に確認する。曖昧なまま「良かったですね/最悪ですね」のトーンを決めない。

## 2. 嘆き・自虐ツイートに「おめでとう/羨ましい」は厳禁

- 投稿の感情（自慢か嘆きか）を先に判定してからトーンを決める。`...` や `^_^` 等のニュアンスも読む。

## 3. 閉じた会話は無理に開けない

- `^_^`＋過去形（「移動しました」）の自己完結報告は実質クローズ。質問リプを投げると不自然。
- **How:** クローズ気味の投稿は「いいね＋フォローして見送り」。相手の“迷い・愚痴・問い”が出た開いた投稿で初めて絡む。リプ周りは数より「開いてる投稿を見抜く」のが効率の肝。

## 4. コールド返信に宣伝・リンク・アプリ名を入れない

- 相手が興味を示してから初めてPachiTrackerを出す（`reply-outreach-playbook.md`）。

## 5. パチンコ機種名・用語を「スルー数」「回数」と混同しない

- 失敗例: 「5SP」を「5スルー（5回スルーした）」と誤読し、「5SPまで粘って」という表現を使った。正しくは「5SP」は海物語シリーズの機種名。
- 「スルーが鉄壁すぎて辛かった」の正確な意味: スルーチャッカーを球が通らない → 電サポ（電チュー）が開かない → 持ち玉が削られる → 1R出玉とサポ増減の数値が悪化 → 遊タイム期待値が削られる、という連鎖。「回転率が低い」という単純な話ではなく電サポが機能しないことが根本原因。
- **How:** 数字＋アルファベットの組み合わせ（例: 5SP, MAX8）は機種名の可能性が高い。スルー・電サポ・サポ増減・持玉比率の関係を正しく理解してから返信する。

## 6. 相手が「すでにやっていること」を質問するな（当たり前質問NG）

- 失敗例: Sくんが詳細データ（1k回転数・1R費用）を自分で計算して投稿しているのに「このデータってその場でメモしてますか？」と聞いた。相手はすでにやっており、反応が薄くなった（「お疲れ様です。その場でメモしてます！」と冷たい一言で終了）。
- **Why:** 投稿内容から明らかに分かることを質問すると「自分の投稿読んでない人」「話が噛み合わない人」と思われる。信頼ではなく疑問符を与える。
- **How:** 返信前に「この人がすでにやっていること・知っていること」を整理してから質問を作る。質問は「相手がやっていないこと」か「もう一段深い話」を聞く形にする。例：「メモしてますか？」→NG / 「メモしたデータ、後で何かに使ってますか？」→OK。
- **再発 (2026-07-03):** C.C.（データカウンタの履歴画像を毎回添付する垢）に「この履歴って毎回撮ってます？」と質問する案を出した。履歴スクショを撮るのはこの層には当たり前の習慣で、同じNGパターン。**候補作成時に必ずこの項目を再確認すること。**

## 7. プロ・期待値稼働勢に「やめ時・勝ち逃げライン」を聞くな

- 失敗例: わーさん（プロ）の5万発投稿に「どこまで出たら終えるかの判断も変わりそう」という切り口で質問案を作った。プロは期待値がある限り打つのが大前提なので、「出玉額でやめる」という発想自体が期待値稼働と噛み合わず、「分かってない人」に見える。
- **Why:** 期待値稼働のやめ時は「期待値が消えた時」（回転率低下・閉店時間・より良い台）であって出玉の多寡ではない。出玉ベースのやめ時質問は遊技勢の発想。
- **How:** 相手のプロフィール・普段の投稿から「プロ/期待値稼働」か「遊技勢」かを先に判定し、プロには期待値・資金管理・台選び・スペック評価の切り口で聞く。遊技勢には収支・記憶・楽しみ方の切り口で聞く。
