# 新規リプ候補の探し方 Playbook（手動検索を効率化する）

「キーワード＋最新タブ」だけだと、直近に呟いた人＝フォロワーの少ないアカウントばかりが出る。
これはXの仕様であり、探し方を変えることで回避する。**X操作はすべて人間が手動で行う**（自動巡回はしない）。

---

## レシピ1: min_faves でエンゲージ済み投稿だけを出す（最重要）

Xの検索窓は演算子が使える。いいねが一定数付いた投稿だけに絞ると、
フォロワーを持つアカウントの投稿だけが残る。

```
パチンコ 収支 min_faves:20 -filter:replies lang:ja
撤退 パチンコ min_faves:10 -filter:replies
期待値 稼働 min_faves:30 -filter:replies
回らない パチンコ min_faves:10
```

- `min_faves:N` … いいねN以上の投稿のみ（N=10でtier A中心、N=50でtier B以上が増える）
- `min_retweets:N` … リポストN以上
- `-filter:replies` … リプライを除外（元投稿だけにする）
- `since:2026-07-01` … 日付で絞る（古いバズ投稿を除外して「今週の投稿」にする）

例（今週のB層狙い）:
```
稼働報告 min_faves:50 since:2026-07-01
```

## レシピ2: ネットワークをたどる（検索より効率が良い）

すでに接触済みの中堅アカウント（matutakenet 14k / syuzior 20k / akira_akiramero 13k）は
「同じ層のフォロワー」を持っている。検索で他人を探すより、彼らの周りを見る方が早い。

1. **接触済みB層アカウントの人気投稿のリプ欄を見る** — そこに返信している人は
   「活発でリプを送る文化のある」パチンコ垢。リプが返る確率も高い。
2. **彼らがリポスト/いいねしている相手を見る** — 同ジャンルの中堅が出やすい。
3. **フォローした直後に出る「おすすめユーザー」** — Xのアルゴリズムが
   同ジャンルの類似アカウントを提示してくれる。フォロー3件/日のついでに回収する。

## レシピ3: 機種名ハッシュタグで稼働報告勢を拾う

「#沖海6」「#エヴァ」など機種タグ＋min_favesで、稼働報告を習慣にしている
アカウント（＝毎日ネタを投稿する、リプ周り対象として最適な層）が見つかる。

```
#沖海6 min_faves:10
#とある魔術の禁書目録 min_faves:10
```

## レシピ4: 検索結果は「話題」タブも見る

「最新」タブは時系列なので小規模垢が多い。「話題」タブはエンゲージメント順なので
中堅以上が上に来る。両方を見る。

---

## 見つけたら: 候補バックログに溜める

見つけた候補はその場でリプしなくてよい。`data/outreach_candidates.csv` に溜めておき、
日々のリプ周りでは「今日足りないtier」から選ぶ。

Claude Codeに スクショ or 「@handle フォロワー数 特徴」を渡せば、
関連性判定・tier推定・接触済み重複チェック・登録までやる。

```
# 手動で足す場合
echo "2026-07-03,handle名,フォロワー数,,見つけた文脈,candidate" >> data/outreach_candidates.csv
```

status: candidate（未接触）→ contacted（リプ済み・reply_outreach_log.csvへ移行）→ skip（対象外と判断）

## 週次の回し方（探す日と送る日を分ける）

- **週1回15分**: レシピ1〜3で候補を10〜15件まとめて発掘 → バックログへ
- **毎日**: バックログから tier バランス（A50/B30/C20）を見て選んで送るだけ
- 毎日ゼロから検索しない。「探す」と「送る」を分けるのが時短の本体。
