# Angle Rotation（切り口の分散）

同じ思想（判断ログ）でも切り口を毎回ずらす。Phase 0 は同一読者に何度も見られるため、
「また同じこと言ってる人」化を避ける。最低でも以下5角度をローテーションする。

| 角度 | 狙い / 例 |
|---|---|
| 記憶のズレ | 共感・拡散。例: 勝った日の記憶だけ残る |
| 入力の面倒さ | 継続設計・信頼。例: 入力が重いと記録しない／楽な判断を選ぶ |
| 続行理由の変化 | 振り返り・保存。例: 打ってる最中と後で理由が変わる |
| 店・台選び | あるある・自分事化。例: 店の印象と実績がズレる |
| UI思想 | プロフィール遷移。例: 実戦中は考えず押せる方がいい |

## 使い方

- **ネタ収集時**（`x-idea-harvest`）: `data/post_log.csv` の theme / hook_type と `data/idea_backlog.csv` の既存ネタを見て、直近が特定角度に偏っていれば別角度を優先する。
- **下書き時**（`x-draft-post`）: 3〜5案は必ず別々の角度から作る。同じ角度に偏らせない。
- **統合ワークフロー時**（`x-growth-company`）: 直近投稿が「記憶のズレ」「判断ログ」に偏っていないか毎回チェックする。

## 偏りチェックの目安

同じ角度が直近3投稿中2つ以上を占めていたら、次は必ず別角度から選ぶ。
